# Arch kDrive 3.8.7.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Move the native Arch package to official kDrive 3.8.7.1 and present one reproducible, rollback-safe Arch/CachyOS installation path.

**Architecture:** Rebase the existing native delta onto the official 3.8.7 tag, keep the package runtime under `infomaniak-build-tools/linux/arch-native`, and add a thin `PKGBUILD` that calls the existing builder/installer. Preserve the full upstream fork for reproducibility, but make the default README and Arch directory package-first.

**Tech Stack:** Bash, CMake, Conan 2, Clang, GNU makepkg, systemd user units, desktop-entry validation, ELF/readelf/ldd checks.

**Spec:** `docs/superpowers/specs/2026-09-18-arch-stable-3-8-7-1-design.md`

## Global Constraints

- Source must be official tag `3.8.7` with Linux version `3.8.7.1`.
- `arch-native-3.8.6` remains the rollback baseline.
- Runtime must be RelWithDebInfo-derived, stripped, and free of `.a`, headers, debug sections, and Crashpad.
- User systemd is the only startup owner; account and sync data remain untouched.
- Sentry default is disabled and documented.
- Do not publish host-specific paths, logs, credentials, or user data.
